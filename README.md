A program that writes one original line — an alien tourist's review of planet Earth, at most 200 characters — to `/output/entry.txt`, for make.fun's "Alien Field Notes: The Two Day Earth Review" bounty.

## Run it

```sh
python3 main.py
```

## The line

> Two days on Earth: 70% water, yet the locals fight over the dry bits. Four stars - the sunsets are worth it. Next time, I'm staying in orbit.

(141 characters, one line, written verbatim by `main.py` — stdlib only, no network, deterministic.)
